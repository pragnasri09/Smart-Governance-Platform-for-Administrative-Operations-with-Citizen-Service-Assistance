## Project Description

CivicPulse is a web platform that connects citizens and government departments for transparent complaint management and communication.

---

## Module Description
The Complaint and Resolution Management module handles the backend factors of the CivicPulse application.  
For now, the Complaint Management part of the module has been developed.  

### Key Features
- Create an API-based entrypoint for the application using GET and POST commands.
- Use a Controller to fetch data from the frontend or the respective calling program.
- Create a new complaint with information such as title, description, category, criticality, and location details (if needed).
- Assign the complaint to the right department based on the selected category and extracted keywords.
- Maintain and display the overall workflow of the complaint from creation to closure.

### Features to be added
- Resolution Management module
- Enhanced workflow management
- Detailed classification of a complaint
